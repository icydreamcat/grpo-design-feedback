# GRPO 模型在多轮非可验证性任务中的行为偏差

一份实验记录反馈：在**艺术设计**这类没有可验证结果的任务上，比较多轮迭代工作流中两种训练模式的模型行为。

## 简述

实验提炼了一个具备完整设计规范与设计能力的平面设计 agent 作为测试版，在同一套素材与流程轮次下，让两个模型各自迭代到符合标准或出现明显异常，观察差异。

**基准对照的一个例子**：同一个「明日方舟·迷迭香」平面合成任务、同一句要求——

| | 版本数 | 用量 | 导出 PSD |
|---|---|---|---|
| GLM | 3 版（1 版崩溃作废） | 8.1M tokens | 86 层 |
| DeepSeek | 9 版（每改一次多一版） | 4.6M tokens | 62 层 |

## 记录到的行为

- 凭空塑造一个指标，让自己的产出合理化
- 照抄其他 agent 的案例、做细微改动后称之为差异化
- 无法建立全局框架以审视整个项目
- 主动绕过审计核查，或反过来单一堆砌审计闸门指标

## 前提

- 实验部分只作对照参考，多数结论来自更早的实证记录，请当作基准看待
- 测试版 agent 体量较小，产出不一定符合人类审美，需要交叉对照
